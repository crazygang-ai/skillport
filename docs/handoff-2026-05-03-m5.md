## 关键 ADR（M5 实施期定的）

1. **ADR-M5-1 — NSAttributedString 替代 WKWebView**（偏离 spec §5.2）
   - 渲染走 `NSAttributedString(data:options:.html ...)`，内部 WebKit 但不执行 JS；预先用 SwiftSoup 剥离 script/style/iframe 等，把所有 href/src 归一化到 http/https/mailto/tel/#/./.. 之后交付渲染
   - 节省一个独立 WebContent 进程，原生文本观感一致
   - 回退路径已预留（`RegistryContentRenderer` 抽象接口），未来若 NSAttributedString 渲染质量不可接受可换 WKWebView

2. **ADR-M5-2 — Install 按钮只支持单-skill repo**
   - `SkillManagerActor.installGitHub(owner:repo:ref:home:installTo:)` 不带 `skillId`，clone 整 repo 到 `~/.agents/skills/<repo>/`
   - 当 skills.sh 的 `RegistrySkill.skillId` != `repo`（多技能子目录）→ Install 按钮禁用 + tooltip 提示"用上方 CLI 命令"
   - 多-skill repo 的 App 内 install 移到 M6/M7 backlog

3. **ADR-M5-3 — i18n 留 M6**
   - 所有 UI 字符串用 `String(localized: ...)` 包了，但暂无 `Localizable.xcstrings` 和 zh-Hans 翻译
   - M6 接了就零改动切语言

## 关键踩坑备忘（M5 新增的）

1. **SwiftSoup 的 `unwrap()` 迭代要自底向上**。从 `getAllElements().array().reversed()` 开始，否则 `unwrap` 后子元素会被重新访问造成死循环

2. **`<a href="#section">` 在 raw string literal 里会咬掉**。要用 `##"..."##` 双井号延长分隔符，否则 `"#` 会被当成字符串结束

3. **`AttributedString.font` 默认吃 SwiftUI.Font 属性**，不是 NSFont。`Domain/Services/RegistryContentRenderer.swift` 要 `import SwiftUI` + 用 `.system(size:weight:)` 之类的 API

4. **`Link` 在 SwiftUI + Markdown 里歧义**。导入两个模块后要 `Markdown.Link` 全限定

5. **skills.sh 的 RSC payload `T` chunk 阈值 50 字节**。太小的 chunk 是噪声，写 test fixture 时 htmlBody 要 ≥ 50 bytes（我踩过 27 字节，fall through 到 Strategy 3 才发现）

6. **MockURLProtocol M1 只有精确 URL 匹配**。M5 扩展了 `stub(urlMatch:status:headers:body:)` 谓词变体 + `requestLog` + `makeSession()`，新旧 async API 保留

7. **xcodegen 的 test target resources 路径不能写成 `Tests/SkillportTests/Fixtures`**。实际路径是 `Tests/SkillportTests/TestSupport/Fixtures`（project.yml 第 63-65 行），新 fixture 文件丢进这个目录即可，不用改 project.yml
