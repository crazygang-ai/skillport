## M6 的 3 条 ADR

1. **ADR-M6-1：Quick Look extension 走"复制 parser 代码"**。未把 `Domain/` 抽 SwiftPM package，以防动到 150+ 测试。Parity 靠 `Scripts/check-parser-parity.sh` CI 校验。
2. **ADR-M6-2：语言切换要求重启 app**。不做运行时热切 — SwiftUI `Environment(\.locale)` 热切 + Bundle.main cache 组合容易踩坑。改 `AppleLanguages` UserDefaults + Toast 提示重启。
3. **ADR-M6-3：QL 注册整个 `net.daringfireball.markdown` UTI**。所有 .md 文件都用我们的渲染 — 系统默认 Text 本就不如 attributed Markdown，算 feature 不是 bug。

## 关键踩坑备忘（M6 新增）

1. **`QLPreviewingController` 的 Swift 6 conformance**：ObjC 协议方法不是 `@MainActor`，`NSViewController` 是。直接 conform 会触发 "crosses into main actor-isolated code" error。用 `@preconcurrency QLPreviewingController` 打掩护

2. **BSD sed 不认 stdin 占位符 `-`**。脚本里 `sed ... -` 在 macOS 会报 "No such file or directory"。改成函数形式 `normalize() { sed ...; }` + 管道调用

3. **`UserDefaults(suiteName:)` 穿透读 `AppleLanguages`**。macOS 对某些 Apple-reserved key（`AppleLanguages` / `AppleLocale` 等）有跨 suite 的全局链，test fresh suite 下仍然返回系统语言。test 必须显式 `defaults.set([...], forKey: "AppleLanguages")` 后再断言，不能假设 fresh suite 是空的

4. **xcstrings 插值 key 用 format specifier**：`String(localized: "\(n: Int) skills installed")` 在运行时查 key = `"%lld skills installed"`。手写 xcstrings 时要用 `%lld` / `%@` 形式，不能写 `\(n)`

5. **extension target 的 sources 不能包含 `@testable`-only 类型**。Extension 里拷贝的 `SKILLMetadata` 要瘦身（只保留 `description/version/allowedTools`），去掉 `extras` 和 `Extras: [String: Any]` 那段 `@unchecked Sendable` 的体力活

6. **`xcodegen` 的 `target: SkillportPreview` dependency** 会自动让 build 把 extension bundle copy 到 `Skillport.app/Contents/PlugIns/SkillportPreview.appex/`。不用额外写 copy-files phase
